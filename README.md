# Sistema de Gestión - Consejo Comunal "Las Margaritas"
Este sistema es una solución web desarrollada para digitalizar y centralizar la información administrativa del Consejo Comunal "Las Margaritas". Permite gestionar de manera organizada los registros de la comunidad, facilitando la transparencia y el acceso a la información financiera, censal y comunitaria.
## 🛠️ Stack Tecnológico
El proyecto se construyó utilizando tecnologías fundamentales para asegurar compatibilidad y facilidad de despliegue en servidores locales:
 * **Frontend:** HTML5 y CSS3 para una interfaz funcional y estructurada.
 * **Interactividad:** JavaScript nativo para validaciones y dinamismo.
 * **Backend:** **PHP** para el procesamiento de datos del lado del servidor.
 * **Base de Datos:** **MySQL** para el almacenamiento relacional de registros.
## ✨ Funcionalidades
 * **Censo Poblacional:** Registro y consulta de datos de los habitantes de la comunidad.
 * **Gestión de Finanzas y Proyectos:**
   * Registro de movimientos económicos (ingresos y egresos).
   * **Manejo de Proyectos:** Control, seguimiento y presupuesto de las obras e iniciativas de desarrollo que vaya a realizar el consejo comunal.
 * **Control Administrativo:** Panel de administración para la gestión de datos clave.
 * **Seguridad:** Sistema de login para proteger el acceso a la información sensible
